Day 1: 工程基建 (Infrastructure & Freeze)
目标：锁定变量，完成作为“显微镜”的 VM 实现。
 * [ ] 1. 锁定协议 (Lock Protocol)
   * 在 Git 上打 Tag：v0.2-experiment-ready。
   * 纪律：严禁再修改 enum Instruction 定义。严禁再增加新原语。
 * [ ] 2. 核心 VM 完工 (vm.rs)
   * 实现 run() 循环的完整逻辑。
   * 关键：实现 Trace/Probe 接口。必须能逐条打印 [PC, Op, Gas, Registers, Heap_Delta]，这是后续分析“智能涌现”的唯一凭证。
   * 关键：实现 ASSERT 指令，确保 Agent 能显式自杀。
   * 关键：实现 Heap 的单调递增分配（ID 不回收），防止指针歧义。
 * [ ] 3. 编译器/汇编器 (assembler.rs)
   * 实现 .l0 文本到二进制/JSON 的转换。
   * 确保支持 SETS (String Literal) 和 Label (JMP loop_start) 解析。
   * 让你可以写 app.l0 而不是手写 JSON。
 * [ ] 4. 验证“自杀 Demo” (suicide.l0)
   * 编写一个故意触发 ASSERT 失败的脚本。
   * 运行它，确保 VM 能正确 Panic 并输出错误日志。
   * 验收标准：看到红色的报错信息，证明“语义防火墙”生效。
Day 2: 科学实验 (Science & Observation)
目标：投放 Agent，捕捉结构性相变。
 * [ ] 1. 编写“绝境任务”套件 (Benchmark Suite)
   * Task A (深渊)：写一个 Prompt，要求 AI 计算阿克曼函数或遍历未知深度树。限制：无 CALL，仅 4 个寄存器。
   * Task B (迷宫)：写一个迷宫环境 Mock。限制：Gas 极低，无法 DFS。逼迫 AI 在 Heap 画地图。
   * Task C (记账)：多臂老虎机环境。限制：延迟反馈。逼迫 AI 在 Heap 记统计数据。
 * [ ] 2. 搭建“培养皿”脚本 (experiment.py)
   * 编写 Python 脚本，自动化调用 DeepSeek/GPT-4 API 生成 .l0 代码。
   * 实现自动评测：编译 -> 运行 -> 捕获 VM 输出 -> 判定存活。
   * 变量控制：设置循环，遍历 Register Count = [2, 4, 8, 16] 和 Gas Limit。
 * [ ] 3. 守夜观测 (The Watch)
   * 批量运行实验（建议跑 50-100 次）。
   * 核心动作：grep 日志。
     * 搜索 Heap 里有没有出现 Return_Addr 模式（递归帧）。
     * 搜索 Heap 里有没有出现连续增长的计数器（记账本）。
 * [ ] 4. 绘制曲线 (The Curve)
   * 统计成功率。
   * 画出 P(\text{Structure} | \text{Resources}) 的图表。寻找那个 S 型曲线的拐点。
