Quick Start

1. Build

cargo build --release --workspace

2. Run Examples

# Standard workflow: ASM -> Bytecode -> Execute
./target/release/l0asm examples/hello_world.asm > hello.l0
./target/release/l0vm hello.l0

# AOT compile to native binary
./target/release/l0cc hello.l0 -o program.c
gcc -O2 program.c -o program && ./program

3. Hello World

# hello_world.asm
SETS 1, "Hello, L-Zero!"
TEXEC 0x5000, 1, 255    # PRINT
HALT

Three-Layer Architecture

+---------------------------------------------------------------+ | Layer 1: ISA Core (52 primitives) | | ------------------------------------------------------------- | | - Register-based operations, compiled into VM | | - ADD, SUB, MUL, DIV, MOD, SCAT, HLEN, REGEX, VSIM, etc. | | - Fast, direct execution | +---------------------------------------------------------------+ | | TEXEC 0x5xxx v +---------------------------------------------------------------+ | Layer 2: Builtins | | ------------------------------------------------------------- | | - String-based I/O, no external process | | - PRINT, INPUT, RAND, TIME, UPPER, LOWER, etc. | +---------------------------------------------------------------+ | | TEXEC 0x3xxx-0x9xxx v +---------------------------------------------------------------+ | Layer 3: Plugins | | ------------------------------------------------------------- | | - External subprocess, JSON-RPC protocol | | - DB, HTTP, File, JSON, AI | | - Cross-language support (Rust, Python, Swift, etc.) | +---------------------------------------------------------------+

ISA Core

52 primitives for computation, memory, vectors, and governance. Register-based, type-safe, deterministic.

Builtins

Built-in I/O, string, and math operations. No external process needed. Fast and simple.

Plugins

External capabilities via JSON-RPC. Database, HTTP, File, AI. Infinitely extensible.

Toolchain

Binary Description
l0vm Virtual Machine - executes .l0 bytecode
l0asm Assembler - compiles .asm to .l0 bytecode
l0cc AOT Compiler - compiles .l0 to C code (with supervisor protocol)

Semantic Computing

L-Zero provides native vector operations for AI agents to monitor semantic drift:

# Create embedding vectors
SET 10, 768            # embedding dimension
VNEW 1, 10             # target vector
VNEW 2, 10             # current state vector

# Compute cosine similarity
VSIM 3, 1, 2           # R3 = cosine_similarity * 1,000,000

# Governance: drift detection
SET 30, 800000         # threshold = 0.8
LATCH 1, 30            # set target vector and threshold
GUARD 2                # check state; TRAP if drift detected

When drift is detected, GUARD triggers TRAP which suspends execution and emits JSON context to stdout for supervisor intervention.

Installation

From Source

git clone https://github.com/geyuxu/L-Zero.git
cd L-Zero
cargo build --release --workspace

From Release Package

# Download and extract
tar xzf l0-lang-v1.0.0-darwin-arm64.tar.gz
cd l0-lang-v1.0.0-darwin-arm64

# User install (recommended)
./install.sh              # Install to ~/.l0

# System install
./install.sh --system     # Install to /usr/local/l0

Environment Setup

# Add to ~/.bashrc or ~/.zshrc
export L0_HOME="$HOME/.l0"
export PATH="$L0_HOME/bin:$PATH"

Why L-Zero?

For AI Agents

Designed for machine generation, not human writing. ASM format optimizes token efficiency and eliminates parsing errors.

Type-Safe

Based on strict Rust Enum definition, ensuring 100% valid instruction structure. No runtime type errors.

Semantic Aware

Native vector operations and governance primitives let AI agents monitor and respond to semantic drift autonomously.

Extensible

52 core primitives + infinite capability via dynamic plugins. Add new tools without recompiling the VM.

AOT Compilation

Compile to native C code for maximum performance. Same governance protocol works in both VM and AOT modes.

Self-Describing

Query the VM with --info to discover ISA and available tools. Code as documentation.
